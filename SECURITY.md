
# Security Policy

## Supported Versions

Code2Pseudo is currently under active development.
Security updates are provided on a best-effort basis
for the latest development version.

| Version | Supported |
| ------- | --------- |
| Latest development version | :white_check_mark: |
| Older versions and snapshots | :x: |

## Reporting a Vulnerability

If you discover a security vulnerability in Code2Pseudo,
please report it privately.

Use GitHub's Private Vulnerability Reporting feature
available in the repository's Security tab.

Please do not report security vulnerabilities through
public GitHub Issues or Discussions.

When reporting a vulnerability, include:

- A clear description of the vulnerability.
- Steps to reproduce the issue.
- The affected version or commit.
- The potential security impact.
- A proof of concept, if available.

## Response Process

The maintainer will make a best effort to:

- Acknowledge reports within 7 days.
- Investigate and assess the reported vulnerability.
- Provide updates as the investigation progresses.
- Notify the reporter when a fix is available.

If a report is accepted, the maintainer will work on
a fix and coordinate responsible disclosure.

If a report is declined, an explanation will be
provided whenever possible.

Response times are best-effort and are not guaranteed.
